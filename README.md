# Funcionamiento de un DEA (Desfibrilador Externo Automatico) 

### Funcionamiento de un DEA (Desfibrilador Externo Automático)

Una simulación interactiva de realidad virtual desarrollada en **Unity** diseñada para educar y entrenar a los usuarios en el protocolo correcto de uso de un Desfibrilador Externo Automático (DEA). 

### Descripción del Proyecto

Este proyecto busca concientizar y capacitar de forma didáctica sobre los pasos críticos que se deben seguir al utilizar un DEA. A través de una interfaz interactiva y scripts lógicos, el usuario aprenderá a identificar el estado del paciente, colocar los parches correctamente y administrar la descarga siguiendo las imagenes mostradas. 

### Características Principales

* **Guía paso a paso:** Recorrido virtual por las distintas partes de un DEA, además de información visual sobre el correcto uso y la Normativa que tiene este dispositivo.
* **Interactividad dinámica:** El usuario debe interactuar con los elementos del escenario (Botones de información mediante selección interactiva con la mirada).
* **Retroalimentación visual:** Imágenes, video, y interacción en tiempo real con el dispositivo, en el que se pueden observar sus componentes fisicos.

### Requisitos y Tecnologías

* **Motor de Desarrollo:** Unity 2022.3.62F2
* **Plataforma Objetivo:** PC / Android.
* **Lenguaje de Programación:** C#.

### Instalación y Uso

### Para Desarrolladores (Editar el proyecto en Unity)

1. Clona este repositorio en tu máquina local: 

bash

git clone https://github.com/B3NA23/Funcionamiento-de-un-DEA-Desfibrilador-Externo-Automatico.git

Usa el código con precaución.
2. Abre **Unity Hub**.
3. Haz clic en **Add** (Añadir) y selecciona la carpeta raíz del proyecto clonado.
4. Asegúrate de tener instalada la versión de Unity correspondiente y abre el proyecto.
5. Dirígete a la carpeta Assets/Scenes y abre la escena principal para comenzar.

### Para Usuarios (Probar la build)

*(Opcional: Si tienes un enlace de itch.io o una sección de "Releases" en GitHub, puedes colocar los pasos aquí)* 

1. Descarga la última versión desde la sección de [Releases](../../releases).
2. Ejecuta el archivo .exe (o ejecutable correspondiente).

### Estructura del Proyecto

El repositorio cuenta con la estructura estándar de un proyecto de Unity: 

* Assets/: Contiene todos los modelos 3D, texturas, audios, materiales, escenas y scripts de C#.
* Packages/: Gestión de dependencias y paquetes internos de Unity.
* ProjectSettings/: Configuraciones globales del motor para este proyecto.
